Cybersecurity Vulnerabilities & CVEs
1 msgs
A notable sandbox escape vulnerability (CVE-2026-47128) was disclosed in the nono sandbox on Linux. The exploit leverages a Landlock/seccomp policy gap where permitted Unix domain socket access enables reaching the user's systemd D-Bus socket to execute systemd-run --user, crossing from sandboxed to host-level execution.

Landlock/seccomp policy gap allows sandboxed code to reach per-user systemd D-Bus socket and invoke systemd-run --user. Defenders should treat D-Bus/socket access as a privileged boundary in sandbox threat models.
